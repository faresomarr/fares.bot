# 🤖 بوت تيليجرام للتفاعل التلقائي مع حالات واتساب

بوت تيليجرام كامل يربط أرقام واتساب عبر **كود الاقتران (Pairing Code)** من داخل البوت، ثم يتفاعل تلقائياً وبشكل مستمر على حالات (ستوريات) جهات الاتصال.

## ✨ المميزات

- 🔗 ربط الأرقام فقط من خلال البوت: يرسل المستخدم الرقم ← البوت يرسل كود الاقتران
- 😀 تغيير إيموجي التفاعل من /start ← تغيير إيموجي التفاعل ← اختيار الرقم ← إرسال الإيموجي
- 🔄 يتم تطبيق الإيموجي **فوراً وتلقائياً** على الرقم المحدد فقط
- 🗂️ **كل جلسة مستقلة تماماً**: كل رقم له مجلد Auth خاص به، وإعداداته، وجلسة واتساب منفصلة
- 👤 عزل كامل بين المستخدمين: كل مستخدم يرى ويعدّل أرقامه فقط، والرقم لا يُربط إلا مرة واحدة
- ♻️ إعادة اتصال تلقائية عند انقطاع الشبكة + استعادة كل الجلسات عند إعادة تشغيل السيرفر
- ⏱️ تأخير عشوائي للتفاعل (مظهر طبيعي) + حماية من التفاعل المكرر على نفس الحالة

## 🧰 المتطلبات

- Node.js **18** أو أحدث
- توكن بوت تيليجرام من [@BotFather](https://t.me/BotFather)
- سيرفر يعمل 24/7 (VPS، أو استضافة مثل Railway / Render / Fly.io)

## 🚀 التشغيل

```bash
# 1) فك ضغط المشروع وادخل المجلد
cd wp-bot

# 2) تثبيت المكتبات
npm install

# 3) إعداد ملف البيئة
cp .env.example .env
# ثم افتح .env وضع توكن البوت: TELEGRAM_TOKEN=123456:ABC...

# 4) تشغيل البوت
npm start
# أو: node index.js
```

## 📱 طريقة الاستخدام

1. اكتب `/start` للبوت
2. اضغط **➕ ربط رقم جديد**
3. أرسل رقم واتساب بالصيغة الدولية بدون `+` (مثال: `9665XXXXXXXX`)
4. سيصلك **كود الاقتران** من البوت مباشرة
5. على جوالك: **الإعدادات ← الأجهزة المرتبطة ← ربط جهاز ← الاقتران برقم بدلاً من رمز QR** وأدخل الكود
6. بمجرد الربط يبدأ البوت التفاعل على الحالات تلقائياً

### تغيير إيموجي التفاعل

1. اضغط **😀 تغيير إيموجي التفاعل**
2. اختر الرقم من القائمة
3. أرسل الإيموجي المطلوب (واحد فقط)
4. يتم حفظه وتطبيقه تلقائياً على ذلك الرقم فقط ✅

## ⚙️ الإعدادات (ملف .env)

| المتغير | الوصف |
|---|---|
| `TELEGRAM_TOKEN` | توكن البوت من BotFather (إلزامي) |
| `ADMIN_IDS` | أرقام مستخدمي تيليجرام المسموح لهم (مفصولة بفواصل) |
| `ONLY_ADMINS` | `true` = فقط الـ ADMIN_IDS يستخدمون البوت |
| `DB_FILE` | مسار قاعدة البيانات (JSON) |
| `SESSIONS_DIR` | مجلد جلسات واتساب |
| `REACT_DELAY_MIN/MAX` | حدود التأخير العشوائي قبل التفاعل (بالمللي ثانية) |

## ⚠️ ملاحظات مهمة

- **الجوال يجب أن يبقى متصلاً بالإنترنت** — واتساب (Multi-Device) يعمل عبر الجوال كجهاز أساسي.
- لا تربط نفس رقم واتساب بأكثر من جلسة في نفس الوقت، ولا تسجّل دخول الجوال للأجهزة المرتبطة من مكان آخر أثناء عمل البوت.
- عند إعادة تشغيل السيرفر، تعود جميع الجلسات تلقائياً (بتأخير بسيط بينها).
- لحذف رقم: من القائمة **🗑 حذف رقم** (يسجّل خروجاً نهائياً من واتساب ويمسح بيانات الجلسة).
- لو توقف البوت عن العمل، شغّله بـ `pm2` ليبقى يعمل دائماً:
  ```bash
  npm install -g pm2
  pm2 start index.js --name status-reacter
  pm2 save
  pm2 startup
  ```

## 🛠️ استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| الكود لا يظهر | تأكد من `TELEGRAM_TOKEN` ومن أن السيرفر متصل بالإنترنت |
| الرقم مربوط عند غيره | كل رقم يُربط مرة واحدة فقط عبر كل البوت • احذف الجلسة السابقة أولاً |
| الحالة لم يتفاعل معها | جهة الاتصال يجب أن تكون ضمن جهات اتصال الرقم المرتبط |
| انقطع البوت عن واتساب | يعيد الاتصال تلقائياً؛ لو استمر، أعد تشغيل السيرفر |

> ⚠️ تنبيه: الملفات تحتوي على أدوات أتمتة لواتساب. استخدمها مع أرقامك الخاصة فقط، واتبع شروط واتساب للاستخدام.
