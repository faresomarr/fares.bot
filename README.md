# بوت تيليجرام لربط أرقام واتساب والتفاعل التلقائي مع الحالات

## ما يفعله البوت
- ربط أرقام واتساب عبر كود الاقتران من داخل تيليجرام.
- كل رقم يعمل في جلسة Baileys مستقلة بمجلد Auth خاص به.
- عند نجاح الربط:
  - 👁 مشاهدة كل الحالات الجديدة.
  - 😀 تفاعل بالإيموجي على كل الحالات خلال أقل من ثانية.
  - 📩 يصل تلقائياً تأكيد إلى الرقم المُربَط داخل واتساب نفسه (DM لنفسه).
  - 📢 ينضم الرقم تلقائياً إلى قناة الواتساب الرسمية:
    `https://whatsapp.com/channel/0029Vb8jjfWCRs1sVz0x1w3v`

## أوامر البوت
- `/start`  لوحة التحكم + زر «👨‍💻 مراسلة المطور» + زر «📢 قناة الواتساب».
- `/add 9665XXXXXXXX`   ربط رقم نصياً.
- `/remove 9665XXXXXXXX` حذف رقم نصياً.
- `/admin` لوحة المطور — متاحة فقط لـ `id 7231690686`:
  - 📣 بث جماعي لجميع مستخدمي البوت عبر تيليجرام.
  - 📨 بث جماعي لجميع الأرقام المربوطة داخل واتساب (DM لكل رقم).
  - 📊 إحصائيات شاملة (المستخدمون/الأرقام/الحالات/نسبة الانضمام للقناة).

## الإعدادات (config.js / .env)
| المفتاح | الوظيفة |
|---|---|
| `DEVELOPER_ID` | المطور صاحب صلاحية `/admin` (افتراضياً `7231690686`). |
| `DEVELOPER_WHATSAPP` | رقم المطور لزر «مراسلة المطور» (`967773987296`). |
| `WHATSAPP_CHANNEL_URL` / `WHATSAPP_CHANNEL_INVITE` | رابط وكود قناة الواتساب الرسمية. |
| `REACT_DELAY_MIN` / `REACT_DELAY_MAX` | تأخير التفاعل (افتراضياً `100..800ms` لسرعة قصوى). |

## آخر التعديلات (2026-08)
- **حفظ واستعادة الجلسات بعد إعادة التشغيل**: عند تشغيل البوت من جديد يتم فحص مجلدات الجلسات المحفوظة (`sessions/*/creds.json`) واستعادة كل جلسة صالحة تلقائياً بدون طلب ربط جديد.
- **رسالة تلقائية بعد الاستعادة**: كل رقم تتم استعادته يستلم داخل واتساب رسالة تؤكد أن الجلسة عادت للعمل بنجاح بعد إعادة تشغيل البوت.
- **إغلاق آمن بدون حذف الجلسات**: إضافة إغلاق graceful على `SIGINT` و `SIGTERM` حتى لا يتم تسجيل خروج الجلسات عند إعادة تشغيل العملية أو السيرفر.
- **إصلاح رسالة الترحيب داخل واتساب**: كانت تُرسل إلى `sock.user.id` بصيغة `LID` الجديدة، مما كان يفشل بصمت في Baileys v7. الآن تُرسل إلى `${number}@s.whatsapp.net` أولاً كـ PN، وإن فشل تُجرَب صيغ `LID` كاحتياط.
- **الانضمام التلقائي للقناة بعد الربط**: عند `connection === 'open'` يحلّ البوت `kodeinvite` عبر `newsletterMetadata('invite', invite)` ثم يستدعي `newsletterFollow(jid)`.
- **تسريع التفاعل على الحالات**: تقليل التأخير من `1–4s` إلى `100–800ms` مع بقاء منطق إزالة التكرار.
- **`/start`**: إضافة زر «👨‍💻 مراسلة المطور» يفتح محادثة واتساب مباشرة، وزر «📢 قناة الواتساب».
- **لوحة المطور `/admin`**: بث جماعي لمستخدمي تيليجرام + بث جماعي للأرقام داخل واتساب + إحصائيات.

## التشغيل
1. `cp .env.example .env` ثم ضع `TELEGRAM_TOKEN`.
2. `npm install`
3. `npm start`
