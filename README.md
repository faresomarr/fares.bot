# Fares Bot — بوت ربط واتساب + موقع رسمي متكامل

مشروع واحد يجمع بين:
- بوت تيليجرام لربط أرقام واتساب عبر كود الاقتران.
- التفاعل التلقائي مع حالات واتساب.
- موقع رسمي فاخر ومتجاوب.
- نظام تعليقات واستفسارات داخل الموقع.
- لوحة مطور للرد على التعليقات.
- إحصائيات كاملة مباشرة من نفس قاعدة بيانات البوت.
- إرسال رابط الموقع داخل الرسائل التلقائية بعد الربط أو استعادة الجلسة.

## مميزات الموقع
- واجهة احترافية مرتبة ومتجاوبة على الجوال والكمبيوتر.
- صفحة رئيسية تعرض:
  - وصف البوت.
  - روابط البوت الرسمية.
  - إحصائيات مباشرة.
  - نموذج إرسال التعليقات.
  - قائمة آخر التعليقات وردود المطور.
- صفحة إدارة للمطور على المسار `/admin`.
- الرد على التعليقات عبر `SITE_ADMIN_TOKEN`.

## مميزات الإحصائيات
يعرض الموقع ولوحة المطور إحصائيات مثل:
- عدد مستخدمي البوت.
- عدد الأرقام المرتبطة.
- الأرقام المتصلة / المنتظرة / المسجل خروجها.
- الأرقام المنضمة للقناة.
- مشاهدات الحالات.
- تفاعلات الحالات.
- أكواد الاقتران الصادرة.
- عمليات الربط الناجحة.
- إعادة الاتصال.
- الرسائل التلقائية المرسلة داخل واتساب.
- التعليقات الكلية / المردود عليها / بانتظار الرد.

## التشغيل المحلي
```bash
cp .env.example .env
npm install
npm start
```

## أهم متغيرات البيئة
انسخ `.env.example` إلى `.env` ثم عدل القيم التالية:
- `TELEGRAM_TOKEN` توكن بوت تيليجرام.
- `PORT` منفذ الموقع.
- `WEBSITE_URL` رابط موقعك النهائي بعد النشر، وهو الرابط الذي سيتم تضمينه داخل الرسائل التلقائية.
- `SITE_ADMIN_TOKEN` رمز الدخول إلى لوحة المطور بالموقع.
- `DEVELOPER_WHATSAPP` رقم المطور.

## صفحات الموقع
- الصفحة الرئيسية: `/`
- لوحة المطور: `/admin`
- فحص الخدمة: `/health`

## ملاحظات مهمة
- قاعدة البيانات محفوظة في `data/db.json`.
- جلسات واتساب محفوظة داخل `sessions/`.
- يفضّل نشر المشروع على Render أو Railway أو VPS مع ضبط `WEBSITE_URL` على الرابط الحقيقي النهائي.
- عند تشغيل المشروع ستعمل واجهة الويب والبوت من نفس التطبيق.
